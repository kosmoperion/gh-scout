# gh-scout: maritime shipping & logistics software

**Thin ecosystem — real primitives exist**

No production-grade OSS for full logistics platforms (fleet management,
port ops). Pass 1 found only student repos, max 2 stars. Pass 2 — searching
the underlying protocol instead of the product — found a real ecosystem.

## 🟢 Adopt, don't rebuild the decoder

**schwehr/libais** — 260★ · C++ · license: none asserted ⚠️
> The reference AIS decoder. No explicit license is a real constraint.

**ais-dotnet/Ais.Net** — 152★ · .NET · AGPL-3.0 ⚠️
> Millions of sentences/sec. AGPL blocks closed-source use.

**BertoldVdb/go-ais** — 69★ · Go · MIT ✅
> Implements ITU-R M.1371-5. Clean license — strongest adopt candidate.

## Take

Don't expect a finished logistics platform — that market is proprietary.
Building on vessel tracking? **go-ais (MIT)** is the cleanest start.
